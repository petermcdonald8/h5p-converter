# H5P Lesson Drafter

Turns lecturette transcripts into a draft H5P lesson form (PowerPoint), then converts it into an H5P Course Presentation.

Open the page, click **Load muscle physiology demo** to try it, or fill in your own lesson.

- `index.html`: the drafter and converter page
- `template.pptx`: the lesson form template (also built into the page)

An independent tool, not an official University or H5P product.
