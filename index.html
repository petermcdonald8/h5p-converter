H5P Lesson Form Drafter

Add your lecturette titles and transcripts, and Claude fills in the H5P lesson form (PowerPoint) for you to edit and finalise.

How this works
  1. Enter the lesson details and choose how many lecturettes there are.
  2. For each lecturette, add a title and the transcript (.txt, .vtt or .srt file, or pasted text), and choose how many of each question type you want.
  3. Click Draft lesson form. Claude writes the learning outcomes, the "what to watch for" captions, questions with feedback, bridges, hook, recap, take-home messages and review questions.
  4. Download the PowerPoint, then check, edit and finalise it. It's a draft, and the academic is responsible for the content.
  5. Run the finished form through the H5P converter as usual.

Drafts are created by Claude (Anthropic). Only the transcripts and the settings on this page are sent.

Testing? Fills in 5 made-up lecturettes so you only need to add an API key.

How do I get an API key?
  1. Go to console.anthropic.com and sign up. This is separate from a normal Claude.ai account.
  2. Open Billing and add some credit. Each lesson form costs a small amount.
  3. Open API Keys, click Create Key and give it a name, e.g. "H5P drafter".
  4. Copy the key. It's a long code starting with sk-ant-, not a link, and it's only shown once, so copy it straight away.
  5. Paste it into the box above. Tick "Remember key" to avoid pasting it every time.

Treat the key like a password. Anyone with it can spend your credit. If it leaks, delete it in the console and create a new one.

6Draft

  1. Paste the prompt into your AI, e.g. Claude, ChatGPT or Copilot. If it says the message is too long, attach the downloaded .txt file instead and type "Follow the instructions in this file."
  2. Copy the AI's whole reply and paste it here. If the reply stops part-way, type "continue" and paste all the parts in, one after another.

    Add images (optional)

    For each image box: click Copy AI image prompt and paste it into an AI that makes images (e.g. ChatGPT, Copilot or Gemini), or use a picture from your image bank. Save the image, choose it here, then click Rebuild PowerPoint with images. Always check AI images for accuracy.

    7Convert to H5P

    Check the PowerPoint first and add your pictures. Then turn it into an H5P file here. Your file stays on your computer.

    How to add the H5P file to your course
    1. Open H5P in your learning management system (e.g. the H5P tool in Canvas or Moodle, or h5p.com).
    2. Choose Add content (or New content), then Upload, and select the .h5p file you downloaded.
    3. Check each slide in the H5P editor. Add any lecturette videos that didn't have a link in the form.
    4. Save, then add the activity to your module.

    Pictures added in PowerPoint come through. Image boxes without a picture show an "Image to be added" placeholder: replace it with your picture in the H5P editor. If the upload reports a library version problem, ask your H5P administrator to update the H5P content types.
